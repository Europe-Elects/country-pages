# Europe Elects country pages – WordPress embed codes

All countries use the same file: `https://europe-elects.github.io/albania_webpage/index.html`. Change that one file and every country page updates.

Paste the block for a country into a **Custom HTML** block on that country's WordPress page. The `<script>` line resizes the frame to fit; it is only needed once per WordPress page.
